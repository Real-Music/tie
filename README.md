# Task
Developed an online platform to create Avatar and for daily prayer, the brethren can use it to pray for at least 15 minutes

### This Project uses the following:
- [React.js](https://vite.dev/guide/#scaffolding-your-first-vite-project)
- [React Router Dom](https://reactrouter.com/)
- [Zustand](https://zustand-demo.pmnd.rs/)
- [Zustand Persist](https://www.npmjs.com/package/zustand-persist)
- [Chakra UI](https://www.chakra-ui.com/)

### How To Setup The Project
This project uses Node.js >=20. If you don't have v20 installed and still want to run the project, open ```package.json``` and delete the ```engine``` key.
- Clone the repo.
- Open the terminal and run this command to install all packages
```
npm install --save
```
- To run in dev mode
```
npm run dev
```
- To build for prod
```
npm run build
```
